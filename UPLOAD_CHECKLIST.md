# GitHub upload checklist

Upload the **contents of this folder** to the root of the GitHub repository.

Required:
- `README.md`
- `requirements.txt`
- `CITATION.cff`
- `notebooks/`
- `results/`
- `figures/`

Do not upload:
- old/incorrect intervention notebooks
- rejected conference PDFs
- manuscript review drafts
- API keys, access tokens, passwords, or private cloud-drive credentials
- a redistributed copy of the complete MedMCQA benchmark unless its license explicitly permits redistribution

After upload:
1. Open each notebook on GitHub and confirm it renders.
2. Confirm the README is visible on the repository front page.
3. Create a normal GitHub release tagged `v1.0.0` only after Zenodo has been connected to the repository.
