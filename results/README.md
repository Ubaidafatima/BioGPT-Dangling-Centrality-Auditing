# Results included in this repository

The CSV files in this folder reproduce the aggregate numerical results reported in the manuscript.

- `overall_prediction_performance.csv`: BioGPT accuracy and mean predicted-option probability for the 200-question analysis.
- `dangling_centrality_summary.csv`: summary statistics across 3,568 analysed tokens.
- `intervention_faithfulness_summary.csv`: mean signed probability drops, flip rates, and mean AOPC for 199 evaluable intervention questions.
- `paired_wilcoxon_summary.csv`: paired one-sided Wilcoxon p-values reported for the two principal comparisons with random deletion.
- `roc_auc_summary.csv`: secondary correctness-discrimination ROC-AUC values.
- `correlation_summary.csv`: correlations reported in the manuscript.

These are derived summary results, not a redistributed copy of MedMCQA. Detailed per-question outputs can be regenerated by running `notebooks/03_Intervention_Faithfulness.ipynb` under the same computational setup.
